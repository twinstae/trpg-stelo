# 핵심 캐릭터

## 핵심 캐릭터 요약

핵심 캐릭터는 다음 내용으로 시작합니다.

- 힘 8 / 속력 8 / 지성 8
- 힘, 속력, 지성에 원하는 대로 나눠 넣을 수 있는 추가 점수 6점
- 가벼운 부상 세 번 / 중간 부상 세 번 / 심각한 부상 세 번을 버틸 수 있는 여력
- 분발: 1
- 사이퍼 제한: 2
- 경장 무기를 불이익 없이 사용
- 어떤 방어구도 불이익 없이 사용할 수 없음
- 장르 기능 두 가지
- 선택: 장르 기능 하나에 무능을 갖는 대신 장르 기능을 하나 더 얻음
- 적당한 옷 한 벌, 다소 비싼 물건 하나를 살 수 있는 여윳돈, 그리고 (플레이하는 장르에 맞는) 기본 장비 한 세트

핵심 캐릭터는 기능 두 개 또는 세 개로 시작하며, 각각 서로 달라야 합니다. 직업이 있는 현실 세계 캐릭터라 기능을 하나 더 고를 수 있다면, 그 기능 역시 겹치지 않아야 합니다. 결국 1등급에는 같은 기능을 두 번 훈련(전문화)할 수 없다는 뜻입니다.
