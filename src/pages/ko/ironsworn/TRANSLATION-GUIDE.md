이 문서는 **철의 맹세(Ironsworn)** 규칙서 영/한 대역의 작업 규칙입니다. 용어는 [`GLOSSARY.md`](./GLOSSARY.md), 진행 상황은 [목차](/ko/ironsworn)를 보십시오.

## 0. 원고 파일 구조

| 종류 | 위치 | 비고 |
| --- | --- | --- |
| 원천 | `Ironsworn-Rulebook.pdf` | 루트. 40MB라 git에 넣지 않는다 |
| 영어 원문 | `src/data/ironsworn/en/<슬러그>.md` | `bun scripts/ironsworn-extract-rulebook.mjs`가 PDF에서 자동 생성. 직접 고치지 않음 |
| 한국어 번역 | `src/data/ironsworn/ko/<슬러그>.md` | **번역은 여기에만** 쓴다. frontmatter 없이 본문만 |
| 단위 목록·상태 | `src/data/ironsworn/chapters.ts` | 스크립트가 생성. 상태는 한국어 원고 파일의 유무로 정해진다 |
| 대역 렌더 | `src/pages/ko/ironsworn/[slug].astro` | 절 단위로 좌우 출력 |

원문과 번역은 **헤딩(`##` 이상) 절 단위로 1:1 짝지어** 나란히 렌더됩니다. 그래서 **헤딩의 개수·순서·깊이를 원문과 똑같이 유지해야 합니다.** 어긋나면 스크립트나 빌드가 어느 절인지 알려 주며 실패합니다.

번역이 없는 단위는 `status: "pending"`이 되어 사이트가 영어 원문만 보여 줍니다. 그것이 정상 상태입니다.

## 1. 문체

| 항목 | 규칙 | 예 |
| --- | --- | --- |
| 종결 | **“~합니다 / ~하십시오”** (던전월드 2 대역과 같게) | “+2 모멘텀을 얻습니다.” |
| 규칙 동사 | 굴립니다, 표시합니다, 더합니다, 얻습니다, 겪습니다, 정합니다 | |
| 2인칭 | 단수 **당신**, 플레이어 집단 **여러분** | “당신은 모멘텀을 불태웁니다.” |
| 캐릭터 | 성별을 특정하지 않음. 필요하면 문장을 비틀어 씀 | |
| 마스터 안내 | **“~하십시오”** | “값을 치르십시오.” |
| 강조 | 원문의 굵게(`**`)는 살리고, 기울임은 용어·액션 이름에만 | |

문장은 짧게 끊고, 수동태와 “~하는 것이 가능합니다” 같은 번역투를 피합니다.

## 2. 판정 표기

| 원문 | 한국어 |
| --- | --- |
| roll +iron | **+강철** 판정 |
| add +1 | +1을 더합니다 |
| On a strong hit, … | **강타**면, … (액션 상자에서는 `**강타**면`으로 굵게) |
| On a weak hit, … | **약타**면, … |
| On a miss, … | **실패**면, … |
| take +2 momentum | +2 모멘텀을 얻습니다 |
| suffer -1 momentum | -1 모멘텀을 겪습니다 |
| mark 1 progress | 진척 1을 표시합니다 |
| inflict 2 harm | 피해 2를 입힙니다 |
| Endure Harm (2 harm) | 피해 견디기(피해 2) |
| page 91 | 91쪽 |
| chapter 4 | 4장 |

* 페이지·장 참조는 `91쪽`, `4장`처럼 붙여 씁니다. 링크를 걸 때는 `/ko/ironsworn/<슬러그>`를 씁니다.
* 숫자 범위는 en dash로: `1–34`.

## 3. 액션 블록

원문에서 액션은 상자(들여쓴 인용)로 들어 있고, 스크립트가 `### 액션 이름` + `> 발동 조건` + `> **강타**면 …` 꼴로 정리해 둡니다. 한국어도 같은 모양으로 옮깁니다.

```markdown
### 공격하기

> **+강철**로 굴립니다. …

> **강타**면 피해 +1을 입힙니다. 주도권을 유지합니다.
```

* 헤딩은 번역하되 **개수와 깊이를 바꾸지 않습니다.**
* 액션 이름은 `한글(English)` 형식으로, **같은 파일에서 첫 등장 한 번만** 영어를 병기합니다.
* 액션 안의 글머리 항목은 `- `로 유지합니다.

## 4. PDF에서 뽑은 원문 다루기

영어 원문은 `pdftotext -bbox-layout`의 좌표를 써서 문단·목록·상자·표로 되살린 것입니다(`scripts/ironsworn-extract-rulebook.mjs`). 그래도 다음은 완벽하지 않습니다.

* **그림이 섞인 쪽**(캐릭터 시트, 모멘텀 트랙 삽화, 주사위 삽화)은 그림 속 숫자가 문장 사이에 끼어들거나, 짧은 조각이 문단처럼 남습니다. 한국어 쪽은 그림을 옮기지 말고 **읽을거리만 깔끔하게** 씁니다.
* 표는 자동으로 마크다운 표가 되지만, 열이 여럿인 표는 한 열짜리 표로 펴 두었습니다(오라클 표). 한국어도 같은 값으로 옮기고, 필요하면 두 열로 다시 묶어도 됩니다.
* 무브(액션) 이름이 예시 상자 안에서 헤딩으로 잡히는 곳이 있습니다(예: 「액션」 단위의 「정보 모으기」). 원문 헤딩 개수를 맞춰야 하니 **그대로 두고 번역합니다.**

원문 자체를 고칠 일이 있으면 원고를 고치지 말고 `RANGES`나 스크립트를 고친 뒤 다시 돌립니다.

```bash
bun scripts/ironsworn-extract-rulebook.mjs          # 원문 재생성 + 헤딩 구조 검사
bun run build                                       # 대역 짝짓기 검사 + 사이트 빌드
```

* 한국어 원고가 헤딩 구조를 어기면 위 두 명령이 **어느 파일의 몇 번째 헤딩인지** 알려 주며 실패합니다.
* `--refresh`를 붙이면 `pdftotext`부터 다시 뽑습니다. PDF 판이 바뀌면 `--toc`로 목차를 확인하고 `RANGES`를 손보십시오.

## 5. 용어 병기 규칙

1. **공식 용어**(예: **모멘텀**, **진행 트랙**)는 **파일당 첫 등장 한 번**만 `(영어)`를 붙입니다.
2. 새 용어를 만들거나 바꾸면 **`GLOSSARY.md`에 한 줄 추가**하고, 같은 커밋에서 기존 파일을 grep해 통일합니다.
3. 액션 이름과 능력치 이름은 [`GLOSSARY.md`](./GLOSSARY.md)의 표를 그대로 씁니다.
4. `fiction`은 **이야기 속 현실**로 옮깁니다(문맥에 따라 **이야기 속에서**, **이야기 속의 상황**). **허구**나 **픽션**은 쓰지 않고, **상황**·**세계**로도 옮기지 않습니다(situation·world와 섞이기 때문). `fictional framing`은 **이야기 속 틀**입니다.
