이 문서는 **던전월드 2 Beta v2.1** 번역 규칙입니다. 용어는 [`GLOSSARY.md`](./GLOSSARY.md), 진행 상황은 저장소 루트의 `DW2_BETA_TRANSLATION_CHECKLIST.md`를 보십시오.

## 0. 원고 파일 구조 (영/한 대역)

| 종류 | 위치 | 비고 |
| --- | --- | --- |
| 영어 원문 | `src/data/dw2/en/<슬러그>.md` | `bun scripts/dw2-split-beta.mjs`가 원문에서 자동 생성. 직접 고치지 않음 |
| 한국어 번역 | `src/data/dw2/ko/<슬러그>.md` | **번역은 여기에만** 쓴다. frontmatter 없이 본문만 |
| 장 제목·상태 | `src/data/dw2/chapters.ts` | `translated` / `pending` |
| 대역 렌더 | `src/pages/ko/awe/dw2/[slug].astro` | 절 단위로 좌우 출력 |

원문과 번역은 **헤딩(`##` 이상) 절 단위로 1:1 짝지어** 나란히 렌더됩니다. 그래서 **헤딩의 개수·순서·깊이를 원문과 똑같이 유지해야 합니다.** 받침이 어긍나면 빌드가 어느 절인지 알려 주며 실패합니다.

기준은 두 가지입니다.

1. **톤·문체·기계 용어는 [던전월드 한국어 공개판](https://sites.google.com/view/dwtemporary)(1판)을 따른다.**
2. **2.1에 새로 생긴 개념은 1판 어투로 새로 짓되, 같은 문서 안에서 흔들리지 않게 고정한다.**

## 1. 문체

| 항목 | 규칙 | 예 |
| --- | --- | --- |
| 종결 | 1판과 같은 **“~합니다 / ~하십시오”** | “적에게 피해를 주고 자기는 공격을 피합니다.” |
| 규칙 동사 | **말합니다, 고릅니다, 표시합니다, 지웁니다, 잠급니다, 얻습니다, 잃습니다** | |
| GM 훅 | **“어떻게 하나요?”** — 상황에 따라 “그래서 어떻게 하나요?”, “이제 어떻게 하나요?” | |
| 2인칭 | 단수 **당신**, 플레이어 집단 **여러분** | “당신은 조건을 표시합니다.” |
| 캐릭터 | 남녀를 특정하지 않음. 필요한 경우 이름이나 “그/그녀” 대신 문장을 비틀어 씀 | |
| 1판 인용 | 1판 문장을 그대로 옮겨 쓸 때는 **원문 표기를 바꾸지 않음** | “마스터 액션의 이름을 말해서는 안 됩니다.” |

문장은 **짧게 끊고**, 수동태와 “~하는 것이 가능합니다” 같은 번역투를 피합니다. 직역해서 뜻이 흐려질 때는 1판처럼 풀어 씁니다(예: *The enemy’s counterattack* → “적의 반격”).

## 2. 판정 표기

| 원문 | 한국어 |
| --- | --- |
| roll+Str / roll+CHA | **+근 판정** / **+매 판정** |
| 2d6+STR | **2d6+근력** (주사위 설명 절에서만 풀표기) |
| On a 10+ | **10+이면** / 무브 표 안에서는 **10+:** |
| On a 7-9 | **7–9이면** (숫자 사이는 en dash `–`) |
| On a 6- | **6-이면** |
| with adv / dis | **유리(adv)** / **불리(dis)** — 파일 첫 등장에만 영어 병기 |
| mark 1 XP | **경험치 1을 표시합니다** |
| deal/suffer dmg | **피해를 줍니다 / 피해를 받습니다** |
| min dmg / max dmg | **최소 피해 / 최대 피해** |

## 3. 무브(액션) 블록

원문은 무브를 표(`| When you … |` + `| :---- |`)로 감싸고 있지만, 사이트에서 읽기 나쁘므로 **알파 번역처럼 헤딩 + 문단·목록으로 정규화**합니다.

원문:

```
### Trade Blows (+STR or \+DEX)

| When you engage a foe in battle, roll+STR in melee or \+DEX at range …
✦On a 10+, choose one: …
| :---- |
```

한국어:

```markdown
### <a id="trade-blows-(+str-or-+dex)"></a>주고받기(Trade Blows)

**전투에서 적과 맞붙을 때**, 근거리면 **+근 판정**, 원거리(또는 `\#정밀` 무기)면 **+민 판정**을 합니다.

- **10+:** 아래 하나를 고릅니다. …
- **7–9:** 대신 아래 하나를 고릅니다. …
- **6-:** …
```

**표를 그대로 두는 곳**: 장비 목록, 마법 아이템, NPC 스탯블록, 태그 목록, 재물/부 등 실제로 표인 자료.

## 4. 헤딩과 앵커 (중요)

* 원문 헤딩의 `{#anchor}`는 분할·번역 과정에서 **`<a id="anchor"></a>`로 그대로 살려 두었습니다.** 한글로 번역해도 링크가 깨지지 않게 하는 장치입니다. **이 앵커를 지우거나 바꾸지 마십시오.**

```markdown
### <a id="defy-danger-(+variable)"></a>위험 돌파(Defy Danger)
```

* 번역할 때 헤딩을 새로 만들거나 합치거나 빼지 마십시오(대역 짝짓기와 앵커가 둘 다 깨집니다). 원문에 없는 하위 헤딩이 꼭 필요하면 먼저 상의하십시오.

* 액션 제목 형식은 **`한글(English)`** 입니다. 영어 병기는 **같은 장에서 첫 등장 한 번만**.
* 장 사이 링크는 `/ko/awe/dw2/<장>#anchor`, 같은 장 안이면 `#anchor`.
* 원문의 `{#anchor}`를 새로 만들거나 옮길 일이 있으면 반드시 `bun scripts/dw2-check-links.mjs`로 검사합니다.
* 장 대제목(h1)은 대역 페이지 머리말이 대신하므로 원고에는 넣지 않습니다. 그 앵커(`<a id="the-moves"></a>` 같은 줄)만 남깁니다.

## 5. 용어 병기 규칙

1. **공식 용어**(예: **이야기 속 현실**, **유리(adv)**)는 **파일당 첫 등장 한 번**만 `(영어)`를 붙입니다. 이후에는 한국어만.
2. **1판에 이미 있던 용어는 1판 표기를 그대로** 씁니다(예: 위험 돌파, 야영, 황천길, 위력).
3. 1판과 영어 원문이 달라도 **한국어는 1판 표기를 우선**합니다(예: *Spout Lore* → **지식 더듬기**).
4. 새 용어를 만들거나 바꾸면 **반드시 `GLOSSARY.md`에 한 줄 추가**하고, 같은 커밋에서 기존 파일을 grep해 통일합니다.

## 6. 마크다운·기호 처리

| 원문 | 처리 |
| --- | --- |
| `\#close` 같은 태그 | **그대로 유지**. 태그 목록·첫 등장에서 `\#close(근접)`처럼 한글 병기 |
| ◯ / ◯◯◯ uses | **그대로 유지** (“◯ 사용” 등) |
| ☐ / 🗹 / ⬜ / 🤍 / 🛡 | **그대로 유지** (시트 체크박스) |
| ✦ ✶ ✴ 🟎 | **그대로 유지** (원문 무브 마커) |
| `—`, `–` | em dash는 `—`, 숫자 범위는 `–` 유지 |
| 표 안의 `|` | 이스케이프(`\|`) 필요 시 유지 |
| 줄표로 나열된 선택지 | 원문 리듬대로 목록(`-`)으로 분리 |

### 6.1 원문 레이아웃 정리 (`dw2-split-beta.mjs`가 자동 처리)

PDF에서 뽑은 원문은 레이아웃이 망가져 있습니다. 대역으로 나란히 놓았을 때 양쪽 모양이 어긋나지 않도록, 분할 스크립트가 영어 원고를 만들면서 아래를 자동으로 고칩니다. **한국어 원고도 같은 규칙으로 다듬어지므로, 번역할 때 되돌리지 마십시오.**

| 원문 모양 | 처리 |
| --- | --- |
| `\| 무브 본문 \|` + `\| :---- \|` (한 열짜리 견출지 표 203곳) | 표 껍데기를 벗기고 문단으로 만든다. 두 열 이상짜리 진짜 표(피해 주사위·마법 아이템·재물 등)는 그대로 둔다 |
| 한 줄에 몰려 버린 `🟎` `✦` `✶` 마커 | 마커 앞에서 줄바꿈(`  \`)을 되살린다 |
| `\+STR if you … \+DEX if you …` | 능력치 선택지마다 줄을 나눈다 |
| `Abjuration (substance: …) Conjuration (substance: …)` | 계열마다 줄을 나눈다 |
| `- [x] #### 이름` | `#### ☑ 이름` (진짜 헤딩) |
| `- [ ] 장비` | `- ☐ 장비` (네이티브 체크박스 대신) |
| `### 관계 … 깊이`, `### HP STR …`, `### XP …` | 캐릭터 시트 줄이므로 헤딩에서 내려 우측 목차를 더럽히지 않게 한다 |
| `* #### 제목` | `#### 제목` |
| 번호 목록 항목 바로 뒤에 들여쓰기 없이 온 `*`·`-` | 그 항목의 하위 목록으로 들여쓴다(영어 쪽 목록이 중간에 쪼개지지 않게) |

그래도 **한 문단 안에 선택지가 붙어 버린 곳**(예: `choose one: An ally gets a fleeting opportunity You inflict max dmg …`)은 마커가 사라져 복원할 수 없습니다. 이런 곳은 번역에서 목록으로 풀어 씁니다 — 한국어 쪽이 더 읽기 좋아지는 것은 의도된 결과입니다.

숫자와 단위는 붙여 씁니다: **피해 2**, **경험치 1**, **1d6 피해**, **무게 1**, **HP 12**.

## 8. 하지 말 것

* 용어를 임의로 바꾸기(예: **마스터 액션** → “GM 무브”, **조건** → “상태”).
* **픽션** 단독 사용(→ **이야기 속 현실**, **이야기 속**).
* 앵커 `<a id="…">` 삭제, 또는 한국어 슬러그로 링크 직접 작성.
* 원문에 없는 규칙 설명 덧붙이기. 문장을 늘리는 의역(예: “선택을 흔들기”) 금지.
* 표를 문단으로 바꿀 때 기호(◯, ☐, `\#`) 누락.
